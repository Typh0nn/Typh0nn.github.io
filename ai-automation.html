The system
Independent · multi-agent orchestration platform

An orchestration platform that treats LLM calls as something to be governed

Shape
An asynchronous multi-provider LLM layer — Claude, OpenAI, DeepSeek and local Ollama behind one interface, with retry and timeout handling — driven by LangGraph state-machine orchestration so a run has explicit states rather than an open-ended loop. Browser-automation agents on Playwright handle the work that only exists behind a web UI. Deployed on Cloudflare Workers.
Controls
Cost governance: spend tracked per model call against enforced budgets, so a run cannot quietly burn money. LLM-as-judge evaluation layer for automated output quality control. Human-in-the-loop approval gates on the decisions that should not be automated at all — the model proposes, a person signs off.
Why it matters commercially
Local models where they are good enough, frontier models only where they earn it. That is the same instinct as retiring a manual reporting process: work out what the task is actually worth, then build to that.

How I think about building with LLMs

Cost before capability

  • Cheap and local models by default; frontier models only where they change the outcome
  • Spend tracked per call, enforced against a budget
  • Model choice as configuration, never hard-coded

Explicit state, not open loops

  • LangGraph state machines over free-running agent loops
  • Retry and timeout handling as a first-class concern
  • Typed contracts with Pydantic so failures are visible early

A human on the high-stakes call

  • Approval gates before anything irreversible or outward-facing
  • LLM-as-judge for automated quality control on the rest
  • Automation earns trust incrementally, it is not granted upfront
